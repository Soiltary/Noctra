Noctra Link

Your PS4. On your PC.

What this app does

Noctra Link is a launcher and setup companion for the original chiaki-ng client. The PS4's built-in Remote Play service supplies the picture and sound. Console menus and games can be shown; protected content may be blocked.

There is no new PS4 capture PKG in this package. Enable Remote Play and pair a usable console account once.

1. Open Noctra Link

  1. Extract the entire release ZIP into a writable folder.
  2. Run NoctraLink.exe and click Open streaming client.
  3. On first use, accept the official engine download (about 97 MB). Keep the PowerShell setup window open until it finishes. Its download is verified by SHA-256.
  4. The original chiaki-ng client opens. Later launches reuse the local engine.

No administrator access or Python installation is required. First-run setup needs access to GitHub; local streaming uses your home network.

Manual alternative: copy the complete official portable chiaki-ng-Win folder into engine/ beside NoctraLink.exe, preserving every DLL and subfolder.

2. Prepare your PS4

  1. Turn on the console and select the local user you intend to stream.
  2. Connect the PS4 and PC to the same router. Try Ethernet for initial testing.
  3. Open Settings → Remote Play Connection Settings → Enable Remote Play.
  4. Select Add Device when ready to register. This produces a temporary pairing PIN.

Do not update console firmware to use this launcher. It does not install or repair GoldHEN.

3. Pair in chiaki-ng

  1. Select the discovered PS4. If missing, use Settings → Consoles → Register New and enter its local IP. Find it on PS4 under Settings → Network → View Connection Status.
  2. Choose PS4 Firmware ≥ 8.0 for firmware 8.0 and later. Select the appropriate older category for older firmware.
  3. Enter the actual local account's PSN Account-ID in Base64. This is not the display name or the discovered hardware ID.
  4. Enter a fresh Remote Play PIN from the PS4. Console PIN is optional: it refers to a local-user login passcode.
  5. Click Register, then select the registered console to stream.

Optional PSN Internet-connection setup is separate from local manual pairing. PSN Login is not the way to retrieve a locally generated offline Account-ID.

Modified consoles and offline accounts

A properly prepared, locally activated account can be paired without logging into PSN on the console. GoldHEN alone does not prepare the correct account ID.

Apollo Save Tool documents offline activation under User Tools → Activate PS4 Accounts. Apollo is separate and not included or installed automatically.

Do not casually change an existing user's Account-ID: it is associated with that user's saves. Use a separate local test user when evaluating activation. A proposed value in an input box is not proof that activation succeeded.

4. Use the local Account-ID helper

  1. Enter the numeric Account-ID as 16 hexadecimal digits. An optional 0x prefix is accepted.
  2. Click Convert, then Copy.
  3. Paste into chiaki-ng's PSN Account-ID field.

The helper encodes eight little-endian account bytes as Base64. It does not activate or modify accounts, save the entered ID, or send it to a service. If you already have Base64, use it directly in chiaki-ng.

5. Suggested starting settings

SettingStarting value
Resolution720p; try 1080p on PS4 Pro after checking stability
Frame rate60 FPS, or 30 FPS for an unstable connection
CodecH.264 for PS4
Bitrate10,000 Kbps at 720p, then adjust
ControllerUSB to the PC for the first test

Performance depends on your console, PC and network. These are starting values, not guaranteed results.

Troubleshooting

  • Console not found: use the same LAN, avoid guest-network isolation, allow the client on private networks in Windows Firewall, or register by IP.
  • Registration failed: check the actual Account-ID, successful activation, firmware category and a fresh PIN.
  • FTP failed to get IP: reconnect the console to the router and verify its IP. FTP transfers files; it is not required for streaming.
  • IP changed: update the host address or use a router DHCP reservation.
  • Black screen: try another decoder or software decoding. Protected content may be blocked.
  • Setup failed: check access to GitHub, write permission and disk space. Unexpected archive hashes/layouts are rejected.
  • PowerShell blocked by organization policy: use the manual engine-placement method in step 1 without changing system policy.
  • Console sleeps when disconnected: change chiaki-ng's Action on Disconnect preference.

# Branding

Name: **Noctra Link**. Author credit: **By Solitary**.

The blue/violet linked-portal symbol is embedded in the Windows executable and supplied as PNG and multi-resolution ICO assets. The name was chosen for this package; no trademark availability search or registration is implied.

The original icon was produced using the built-in image-generation tool. The PNG is retained unchanged; the ICO contains format-converted/resized copies for Windows. It does not contain PlayStation logos or controller symbols.

Generation prompt:

> Use case: logo-brand. Create a single premium Windows application icon for 'Noctra Link', a local PS4-to-PC streaming companion. No text, no letters, no PlayStation symbols, no trademark logos. A bold sculptural angular bridge/link mark made from two interlocking rounded rectangular portals with one diagonal connection, hinting at an abstract N, readable at 24 pixels. Electric ice-blue and rich violet enamel with restrained luminous edges and subtle satin depth. Centered composition, thick clean silhouette, polished professional desktop software identity. Genuinely transparent background, no background tile, no drop shadow outside the mark. Square 1024x1024 asset, mark occupying about 80 percent of the canvas, equal margins. Not a mockup, no display device, no scenery.

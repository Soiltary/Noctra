# دليل Noctra Link بالعربي

Noctra Link برنامج Windows لتشغيل عميل chiaki-ng وبث صورة وصوت PS4 عبر الشبكة المحلية. يحتاج اقترانًا أوليًا، ويعتمد البث على chiaki-ng وخدمة Remote Play في الجهاز.

## المتطلبات والتنزيل

Windows 10 أو 11 بنواة x64، وجهاز PS4 مفعّل عليه Remote Play، والكمبيوتر والجهاز على الراوتر نفسه. يفضّل الاتصال بسلك للشروع في التجربة. تحتاج اتصالًا بالإنترنت لتنزيل محرك chiaki-ng في أول تشغيل.

1. افتح صفحة الإصدار وحمّل `Noctra-Link-v1.0.1-Windows-x64.zip` وملف `SHA256SUMS.txt`.
2. للتحقق من التنزيل استخدم PowerShell: `Get-FileHash .\Noctra-Link-v1.0.1-Windows-x64.zip -Algorithm SHA256`، وقارن النتيجة بملف البصمة.
3. فك ضغط المجلد كاملًا إلى مكان قابل للكتابة. لا تشغّل البرنامج من داخل ZIP ولا تنقل ملف exe وحده.
4. افتح `NoctraLink.exe` واضغط **Open streaming client**. وافق على تنزيل المحرك الرسمي، بحجم يقارب 97 MB. انتظر اكتمال نافذة الإعداد؛ يفحص السكربت SHA-256 قبل التثبيت.
5. في المرات التالية يُستخدم المحرك المثبت محليًا. لا تحتاج Python أو صلاحيات مدير.

زر GitHub المسمى Code → Download ZIP ينزّل المصدر؛ لتنزيل البرنامج الجاهز استخدم Releases.

## تجهيز PS4 والاقتران

1. شغّل PS4 واختر المستخدم المقصود. افتح Settings → Remote Play Connection Settings → Enable Remote Play.
2. افتح Add Device للحصول على رمز Remote Play مؤقت عند الاستعداد للتسجيل.
3. في chiaki-ng اختر الجهاز المكتشف. إذا لم يظهر، استخدم Settings → Consoles → Register New وأدخل عنوان IP المحلي الظاهر في PS4 تحت Settings → Network → View Connection Status.
4. اختر فئة نظام PS4 المطابقة؛ لفئة 8.0 وما بعدها اختر PS4 Firmware ≥ 8.0.
5. أدخل Account-ID الحقيقي للحساب بصيغة Base64 ثم رمز Remote Play الجديد. اسم الحساب ومعرّف العتاد لا يحلان محل Account-ID. حقل Console PIN اختياري ويخص رمز دخول المستخدم المحلي.
6. اضغط Register، ثم اختر الجهاز المسجّل لبدء البث. وصّل يد التحكم بالكمبيوتر لتجربتها.

## تحويل Account-ID

إذا كان لديك المعرّف الحقيقي في صورة 16 خانة Hex، أدخله في البرنامج ثم اضغط Convert وCopy، والصق Base64 في خانة PSN Account-ID داخل chiaki-ng. يمكن استخدام بادئة `0x`. التحويل محلي، ولا يفعّل حسابًا أو يغيّره ولا يستخرج المعرّف من اسم المستخدم. إذا كان المعرّف لديك بصيغة Base64 فاستخدمه مباشرة.

الحساب المحلي المفعّل مسبقًا يحتاج معرّفه الصحيح. اقرأ [توثيق Apollo المستقل](https://github.com/bucanero/apollo-ps4#offline-account-activation) عند الحاجة لفهم التفعيل المحلي. تغيير معرّف حساب قائم قد يؤثر في ملفات الحفظ المرتبطة به؛ استخدم مستخدم اختبار منفصلًا. البرنامج لا يثبت Apollo أو GoldHEN، ولا يحتاج تحديث نظام PS4.

## إعدادات بداية مقترحة

720p، وترميز H.264، ومعدل 60 FPS أو 30 عند عدم الاستقرار، ومعدل بيانات 10,000 Kbps. جرّب 1080p على PS4 Pro بعد استقرار الاتصال. النتائج تعتمد على الجهاز والكمبيوتر والشبكة؛ قد يمنع PS4 بث المحتوى المحمي.

## حل المشاكل

- الجهاز غير ظاهر: تحقق من الشبكة نفسها، وعزل شبكة الضيوف، والسماح للعميل على الشبكات الخاصة في جدار حماية Windows، ثم جرّب التسجيل بعنوان IP.
- فشل التسجيل: تحقق من Account-ID الصحيح وفئة النظام ورمز اقتران جديد.
- تغير IP: حدّث العنوان أو ثبّته بحجز DHCP في الراوتر.
- شاشة سوداء: جرّب مفكك ترميز آخر أو فك الترميز البرمجي؛ المحتوى المحمي قد يُحجب.
- فشل تنزيل المحرك: تحقق من الوصول إلى GitHub ومساحة القرص وصلاحية الكتابة. لا تتجاوز فحص البصمة عند فشله.
- سياسات المؤسسة تمنع PowerShell: ضع مجلد `chiaki-ng-Win` الرسمي كاملًا داخل `engine/` بجوار البرنامج وفق الدليل الإنجليزي، دون تغيير سياسة المؤسسة.
- الجهاز يدخل السكون بعد قطع الاتصال: راجع Action on Disconnect في chiaki-ng.

نجحت اختبارات التحويل هنا في الوضع العادي ومع NDEBUG، وتطابقت بصمة ZIP المرفق واجتاز فحص سلامة الأرشيف. لم نختبر تشغيل واجهة Windows أو البث الفعلي على PS4 في هذه البيئة. الملف التنفيذي غير موقّع.

كود Noctra Link مرخّص MIT، ومحرك chiaki-ng يحتفظ برخصته الأصلية. راجع [إشعارات الأطراف الأخرى](../THIRD_PARTY_NOTICES.md). المشروع مستقل وغير تابع لسوني أو لفريق chiaki-ng.

عند الإبلاغ عن مشكلة اذكر إصدار Windows والبرنامج ونظام PS4 ونص الخطأ، وتجنب نشر كلمات المرور أو رموز PSN أو ملفات الاقتران.
